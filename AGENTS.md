- Data cache: React Query uses a 30s staleTime and a global MutationCache that invalidates all queries on any successful mutation — so writes must go through useMutation to refresh other pages.
- WHOOP OAuth tokens live in whoop_connections/whoop_oauth_states with no RLS policies (service-role only, via src/lib/whoop.server.ts); clients only see status through server functions — tokens must never reach the browser.
- WHOOP auto-sync: pg_cron calls /api/public/whoop/cron hourly with a token from the service-role-only internal_cron_tokens table (agents cannot write Vault); iPhone uses /api/public/ios/whoop + ASWebAuthenticationSession returning via cove://whoop-callback.
- WHOOP authorization requests only the scopes needed for sync; do not request optional profile access, which can cause WHOOP to reject authorization before showing sign-in.
- WHOOP uses the registered production callback but stores an exact-allowlisted initiating Settings/return-page URL in server-side OAuth state; preview popups notify their same-origin opener with a source-validated status only, preserving the original session without transferring tokens.
- WHOOP webhooks verify timestamped raw-body HMAC with the existing client secret before any database access; persist trace IDs for deduplication and retry unfinished events through the existing hourly callback without changing its schedule or authentication.
- WHOOP account identity comes from permitted cycle/sleep data, not profile scope; resource/date ownership is service-role-only and deletes clear matching imported values only, preserving manual rows and unrelated habit fields.
- Each content leaf owns a unique head using covePageHead or equivalent explicit metadata; shared metadata never includes private health values.
- New accounts must finish setup before other signed-in screens (profiles.onboarding_completed; web gate in the _authenticated layout, iPhone gate in RootView); both platforms save through the same validation and target formulas (web server fn, iPhone /api/public/ios/onboarding). Existing accounts were backfilled as completed.

- Native iOS styling lives in Shared/Theme.swift and named colour assets; bundle registered local typefaces so headings and controls stay consistent offline.
- Native tab navigation keeps independent NavigationStacks in a tagged TabView with its system bar hidden; reserve the custom dock and Coach button using safe-area insets so content never sits underneath.
